# Stage 5E1F — Scientific Review Agent MVP (offline only)

## Scope

This patch introduces a **reusable offline scientific pre-review core** for Velto/CreatorLab. It is deliberately **not** a working online multi-agent service. It provides four specialist reviewer-role contracts, deterministic assignment and adversarial cross-review, hash-bound evidence checks, a durable attempt ledger, modeled cost reservation, and an exception-first owner report.

It has **no** model API client, network transport, production route, Supabase access, Next.js UI integration, paid provider activation, or human-approval mechanism. PR #32 and its Stage 5E1A USD 1.65 generation envelope remain unchanged.

## Files

- `lib/creator/scientificReview/contracts.ts` — versioned TypeScript contracts; strict runtime key/enum/ID validation; no human sign-off.
- `lib/creator/scientificReview/evidence.ts` — exact source document SHA-256, normalized text SHA-256, and UTF-8 passage byte-offset checks. PDF page locators **are not independently verified**.
- `lib/creator/scientificReview/ledger.ts` — atomic exclusive private run directory (0700), fsync-before-dispatch attempt records (0600), no replay on interrupted run; mock cost model.
- `lib/creator/scientificReview/orchestrator.ts` — four roles, two assessments per claim, immutable reviewer tasks, claim-level preliminary classification.
- `lib/creator/scientificReview/reports.ts` — deterministic exception-oriented owner brief.
- `lib/creator/scientificReview/mock.ts` — test-only reviewer; synthetic answers are not scientific assessments.
- `scripts/stage-5e1f-agentic-scientific-review-test.mjs` — 26 isolated synthetic tests, including macOS system-alias compatibility and fail-closed symlink-path checks.

## Install and test in the existing repository

Copy `lib/creator/scientificReview/` and `scripts/stage-5e1f-agentic-scientific-review-test.mjs` to the matching paths in an isolated local working tree. **Do not commit or push at this stage.**

```bash
node --experimental-strip-types scripts/stage-5e1f-agentic-scientific-review-test.mjs
npm run typecheck
npm run lint:changed
npm run test:ci-critical
```

The test is registered in the critical suite after repository-local focused validation. The runner needs Node 22+ and access to local writable temp directories. No `.env` file is needed.

## How a review works

1. Normalize scientific claims (any count up to 1,000; 23 is a fixture target, not a hardcoded restriction).
2. Identify sources by exact title, version, raw document SHA-256, and extracted UTF-8 SHA-256. Supply original document bytes locally, not to models.
3. Require each cited passage to match the normalized document text at exact UTF-8 byte offsets.
4. Preflight two reviewer attempts per claim and modeled budget. A USD estimate **is not a real billing cap**.
5. Create an exclusive run directory. Before each injected mock reviewer callback, durably consume an attempt. An ambiguous/interrupted run cannot be silently replayed.
6. Keep primary/adversarial tasks free of prior judgments. The caller may still share a process or hidden context; therefore the report states `NOT_ESTABLISHED_OFFLINE_MOCK`.
7. Aggregate decisions: `BLOCK` > `INSUFFICIENT_EVIDENCE` > `REVISE` > `PRELIMINARY_PASS` (the latter is only a synthetic/mock classification in this MVP).
8. Write `manifest.json`, `attempt-*-consumed.json`, `attempt-*-result.json`, `report.json`, and `owner-decision-brief.md` under the private run directory.

## Critical limitations and deliberate blockers

- The four roles are **contracts and orchestration positions**, not independently running live AI agents. The bundled reviewer always returns synthetic test results.
- `kind: offline_mock` is an API contract, not OS-level egress isolation. Do not inject arbitrary third-party callbacks with network access into a supposedly offline test environment.
- PDF extracted-text hashes prove consistency with supplied extracted text; they **do not prove** fidelity to the PDF source pages. PDF-backed claims are `INSUFFICIENT_EVIDENCE` until a separately verified source-locator workflow exists.
- Text offsets prove passage inclusion, not that the cited passage scientifically supports a claim. Mock `PRELIMINARY_PASS` never establishes scientific correctness.
- There is no independently reviewed Stage 5E1D package in this archive; the owner-only absolute path on the owner's machine is inaccessible from this environment.
- This ledger is **single-host only**. It is not a multi-host distributed execution authority, a payment cap, a user quota system, or a production provider admission gate.
- No independent human expert sign-off can be generated by AI, and no production approval or `LIVE GO` is implied.
