# Stage 0.10F — Usage, Entitlement, and Margin Controls

Credits, usage, and COGS are separate truths. The existing credit account, reservation, and ledger system remains the only hard customer entitlement mechanism. Usage is aggregated from immutable economic operations across output duration, generation attempts and seconds, images, voice, intelligence, stock, exports, storage, retries, fallbacks, and exact/estimated/unknown/non-billable cost states.

The internal `creator-margin-benchmark-2026-08-22` policy carries the Stage 0.10A Standard, Pro, and Cinematic working anchors and P50/P90/stress envelopes. These are simulation benchmarks—not customer prices, recognized revenue, invoices, or subscription records. Operational margin health is healthy, watch, P90 pressure, stress, or insufficient data. Unknown infrastructure cost makes results provisional and is never converted to zero.

Finished minutes use completed export duration first, then project scene/timeline duration; provider-generated seconds never become finished minutes. Project lifetime and user current-month/rolling-30-day aggregation read existing indexed ledgers. Retries and paid fallbacks retain distinct attempt dimensions; polling and reconciliation do not create usage.

Pre-dispatch economic admission defaults to `monitor`. Setting server-only `VELTO_CREATOR_MARGIN_ENFORCEMENT_MODE=guard` enables controlled denial under pathological pressure. Invalid/unknown exact profile cost always fails closed. Guard mode never activates candidate models or silently downgrades manual premium work. Credits are still checked and reserved independently after economic admission.

`GET /api/creator-usage` returns only the authenticated user's customer-safe credits, exports, finished duration, premium-generation seconds, stock, and storage usage. Project scope verifies ownership. Provider/model identity, COGS, benchmarks, and internal health remain server-only.

Stage 0.10G must use these dimensions to validate actual packages, quality, pricing, and target margin before any commercial launch.
